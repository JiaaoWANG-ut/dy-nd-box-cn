化学反应与定义

第 n 步酸解离（n = 1, 2, 3；省略配位水）：

n = 1:  Ln3+(H2O) ⇌ Ln(OH)12+ + H+
n = 2:  Ln(OH)12+(H2O) ⇌ Ln(OH)2+ + H+
n = 3:  Ln(OH)2+(H2O) ⇌ Ln(OH)3 + H+
Ka,n= [Ln(OH)n(3−n)+][H+] [Ln(OH)n−1(4−n)+] ,pKa,n=−log10Ka,n ,ΔGn=RTln10·pKa,n

计算方法

Shiery 2021 — 计算值（Table 1，298.15 K）

  • pKa1：约束 AIMD（Bluemoon，CP2K/PBE，64 H2O + 3 Cl−）。以配位水的 r(O–H) 为反应坐标，0.99 → 1.40 Å 取 9 个约束点，每点 NVT 15 ps；对约束力 ⟨f⟩ 积分得 PMF，取端点自由能换算 pKa1（误差为 Table 1 所给）。
A(r)=−∫r0r ⟨f⟩r′dr′ ,pKa,1= A(rend)−A(r0)RTln10
  • pKa2、pKa3：M06 团簇（第一壳层水与 OH 显式）+ CPCM 隐式溶剂计算三步反应自由能，以 pKa1 为锚点取相对值；团簇配位数固定：Nd 为 9，Dy 为 8。
pKa,n=pKa,1+ ΔGnM06/CPCM−ΔG1M06/CPCMRTln10 ,n=2,3

Shiery 2021 — 实验值（Table 2）

  • 文献实验值汇编，表中取中位数。注意：第 2、3 步的实验值在数值上更接近累积常数 −log*βn（Ln3+ + n H2O ⇌ Ln(OH)n(3−n)+ + n H+），而论文按逐步常数使用。

本工作 — MD 占据数 → pKa 等效值（300 K）

  • 体系：Ln3+ + 3 OH− + 水（溶液 128 H2O；石墨/水界面 4 种 OH 起始构型 × 50 条），三维周期盒子。
  • 状态 n = Ln 第一壳层内 OH− 的个数（OH = 恰有 1 个最近邻 H 的 O；截断 rc = Ln–O(OH) 径向密度第一极小，3.03–3.47 Å），每 20 fs 取一帧。
  • Pn：n 态的平衡占据概率（溶液取 t ≥ 10 ps，石墨取 t ≥ 50 ps）；未结合的 OH− 有 (4 − n) 个。
  • c1：盒子中 1 个分子对应的浓度，溶液 0.4224 M，石墨 0.3594 M；c° = 1 M。理想溶液，无活度修正。

MD 中直接观测的是 OH− 解离：

Ln(OH)n(3−n)+ ⇌ Ln(OH)n−1(4−n)+ + OH−
Kd,n= [Ln(OH)n−1][OH−][Ln(OH)n] =Pn−1Pn· (4−n)c1c° ,c1=1NAV

与水的自电离 H2O ⇌ H+ + OH−（Kw，pKw = 14）相加即得上面的酸解离反应：

Ka,n=KwKd,n ⇒ pKa,n=pKw+log10Kd,n =14+log10[Pn−1Pn(4−n)c1]

若只出现 n 态（n − 1 态从未出现），假设未出现的态不比出现的态更多，取 Pn−1 = Pn 得上界：

pKa,n≤14+log10[(4−n)c1] (Pn−1:=Pn)
  • 95% CI：2000 次 bootstrap（石墨按轨迹、按起始构型分层重采样；溶液按 10 ps 块重采样）。
  • 换算：ΔG = RT ln10 · pKa，298.15 K 时 RT ln10 = 5.708 kJ/mol，300 K 时 5.743 kJ/mol。
